# Проверки выпуска LocalControl 0.3.1

Обычный релиз публикуется Windows workflow после успешной проверки собранного Setup.exe. Название версии берётся из Directory.Build.props; исходники и README доступны в main.

## Автоматическая проверка перед публикацией

- .NET restore/build и self-contained publish Desktop и Updater; production TypeScript/Vite build.
- 53 проверки Core/API, включая настоящую главную HTML-страницу, ресурсы Desktop/LAN, аутентификацию, права, Origin/Host/CSRF и неизвестные URL.
- 35 проверок собранного интерфейса в браузере на desktop и мобильных размерах.
- Компиляция Unicode NSIS и чтение русских названий компонентов из собранного установщика.
- Установка 0.3.0-dev, запуск старой версии и обновление тем же Setup.exe в папку с кириллицей и пробелами.
- Сохранение настроек, устройств и посторонних файлов при обновлении; совпадение версии EXE и записи «Установленные приложения».
- Проверка установленного HTTP-сервера, HTML, всех подключённых ресурсов и настоящего Windows API.
- Открытие установленного WebView2, отображение интерфейса с настоящей авторизованной сессией, повторный запуск и поднятие существующего окна.
- Удаление работающей программы, всех принадлежащих пакету файлов и записи установки; сохранение настроек, устройств, полученных и посторонних файлов.
- Проверка SHA256 перед загрузкой точного Setup.exe в Releases. JSON-отчёты и снимок WebView2 доступны в QA artifacts соответствующего Actions run.

## Проверки на пользовательском оборудовании

Windows runner не заменяет реальный iPhone/Safari, микрофоны и аудиоустройства. Отдельно проверяются pairing, права телефона, звук и unplug/replug, Wi-Fi interruption, firewall и длительная работа. LAN выключен по умолчанию; локальный HTTP предназначен для доверенной домашней сети.

Установщик включает .NET. WebView2 устанавливается официальным подписанным Microsoft bootstrapper при отсутствии. Сам Setup.exe пока не подписан Authenticode; SHA256 проверяет целостность файла.

Настройки и устройства хранятся в %LOCALAPPDATA%\LocalControl; удаление приложения сохраняет эту папку и полученные файлы.
