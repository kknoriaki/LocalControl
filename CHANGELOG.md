# Изменения

## 0.3.1

- Исправлена ошибка HTTP 404 при открытии главной страницы в Desktop и по LAN: fallback endpoint больше не блокирует статический HTML.
- Повторный запуск поднимает существующее окно вместо сообщения «уже работает».
- В окно, tray, EXE, установщик и мобильный интерфейс добавлен единый логотип: монитор и клавиатура в стиле LocalCloud.
- Исправлена кодировка русских подписей установщика; сборка явно использует UTF-8.
- Setup.exe подходит для первой установки и обновления. Работающая программа завершается перед заменой файлов; версия 0.3.0 закрывается после подтверждения или при явно выбранной тихой установке.
- Прежние файлы сохраняются для отката. Старые ресурсы интерфейса удаляются по манифесту; пользовательские файлы сохраняются.
- После установки проверяются реальный HTTP-сервер, HTML, ресурсы и состояние Windows. При ошибке восстанавливаются прежние файлы.
- Исправлено удаление открытого приложения; сохраняются настройки, устройства, полученные и посторонние файлы.
- Параметр автозапуска синхронизируется с реестром. Вместо поля signed manifest в UI — загрузка нового Setup.exe со страницы Releases.
- Исходники и README перенесены в основную ветку main.
- Добавлены regression tests главной страницы и Windows acceptance: реальные WebView2/API, второй экземпляр, русские компоненты мастера, обновление старого выпуска и uninstall.

## 0.3.0-dev

Первый предварительный Windows-пакет. C#/API и браузерные проверки проходили, но не проверяли выдачу корневой HTML-страницы и полный установленный интерфейс WebView2. Эта граница проверки устранена в 0.3.1.
