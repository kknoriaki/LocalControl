# LocalControl

Управление Windows-ПК с телефона в домашней сети: звук, микрофон, приложения, файлы, буфер обмена и просмотр экрана. Самостоятельный проект; LocalCloud устанавливать не нужно.

**[Скачать установщик](https://github.com/kknoriaki/LocalControl/releases/latest)** · [Что изменилось](CHANGELOG.md) · [Проверки Windows](https://github.com/kknoriaki/LocalControl/actions)

## Установка и обновление

Скачайте **LocalControl-0.3.1-Setup.exe** в Assets последнего релиза и запустите его. Один файл подходит и для новой установки, и для обновления поверх 0.3.0. Исходный ZIP для запуска не нужен.

- Windows 11 x64; .NET уже включён в установщик.
- При отсутствии Microsoft WebView2 установщик предложит установить официальный Runtime. Только для этого шага может понадобиться интернет.
- Выберите папку, ярлык и автозапуск. После установки откройте LocalControl.
- При обновлении установщик предложит закрыть работающую старую версию. Настройки, устройства и полученные файлы сохраняются.
- Повторный запуск открывает существующее окно. Закрытие окна сворачивает приложение в tray; «Выход» полностью завершает его.
- Удаление через «Установленные приложения» закрывает LocalControl и удаляет файлы программы. Пользовательские данные сохраняются.

Перед заменой файлов программа останавливается, а прежние файлы копируются для отката. Установщик проверяет HTML, ресурсы интерфейса и реальный Windows-адаптер после установки. При неудаче восстанавливает сохранённые файлы.

## Подключение iPhone

1. Подключите телефон и ПК к одной домашней сети.
2. Завершите первую настройку, откройте **Подключение**, выберите домашний IPv4 и включите LAN.
3. Откройте QR в Safari. Сверьте код телефона с запросом на ПК и подтвердите нужные права.
4. Аудио, приложения и другие разрешённые действия доступны с телефона. Remote, питание и буфер обмена требуют отдельных разрешений.

LAN выключен по умолчанию. После перезапуска нужна новая телефонная сессия; записи устройств сохраняются. Используется локальный HTTP, поэтому выбирайте доверенную сеть. Полноценный HTTPS/PWA и видеострим пока не входят в поставку.

Если подключение блокирует Windows Firewall, запустите `firewall.ps1` из папки программы в PowerShell от администратора. Правило ограничено Private/LocalSubnet. Само приложение запускайте обычным пользователем.

## Возможности

- Громкость и mute устройств Windows, микрофонов и отдельных аудиосессий.
- Start Menu, App Paths, Steam, пользовательские приложения, избранное, запуск, закрытие и перезапуск.
- CPU, RAM, диски, время работы и сведения об оборудовании.
- Медиакнопки и локально настроенные Discord keybind. Состояние mute в Discord не определяется.
- Передача файлов в обе стороны; текстовый буфер обмена по явному запросу.
- Remote v1: снимки монитора, клики, прокрутка и текстовый ввод с отдельным разрешением.
- Lock, sleep, hibernate, restart/shutdown с подтверждением.
- Пользовательский автозапуск, dark/light/system theme, адаптация под телефон.

## Исходники и сборка

Исходники находятся прямо в `main`: `src/`, `tests/`, `scripts/`, `installer/`, `assets/`. Это обычный проект .NET + React/TypeScript, а не ZIP внутри репозитория.

Для сборки: Windows x64, .NET 10 SDK, Node.js 24, PowerShell 7, NSIS 3.x.

```powershell
pwsh -File ./scripts/build.ps1 -Installer
```

Windows workflow проверяет C#, настоящий HTTP-сервер и production UI; затем открывает установленный WebView2, проверяет повторный запуск, русские подписи мастера, обновление с 0.3.0 и удаление с сохранением данных. Результаты и снимок интерфейса сохраняются в QA artifacts. Обычный релиз публикуется после успешных проверок.

Это проверки на Windows runner. Реальный iPhone/Safari, конкретные аудиоустройства и длительная работа требуют проверки на пользовательском ПК. Установщик пока без Authenticode-подписи.

Настройки, устройства, WebView2 и диагностика: `%LOCALAPPDATA%\LocalControl`. Полученные файлы по умолчанию: `Downloads\LocalControl`. Сторонние лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
